How did I not know about [https://eclecticlight.co](https://eclecticlight.co/2020/01/23/catalina-boot-volumes/)?

> macOS Catalina is the first version of macOS which boots not from a single volume, but from two: a read-only System volume named by default Macintosh HD, and a writeable Data volume with the default name of Macintosh HD - Data. If you upgrade to macOS 10.15 Catalina, your boot volume will effectively be split into those two.
