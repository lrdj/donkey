# Donkey on the Edge

Source for **[donkeyontheedge.com](https://donkeyontheedge.com)** — a
long-running personal blog, built with [Jekyll](https://jekyllrb.com) and
served via GitHub Pages.

## Local development

Requires Ruby and Bundler.

```sh
bundle install
bundle exec jekyll serve   # http://localhost:4000
```

The site builds to `_site/` (gitignored). GitHub Pages builds the `main`
branch automatically on push; the custom domain is configured via the
`CNAME` file.

## Site data

A few build inputs are precomputed and committed, because GitHub Pages
runs Jekyll only (no build scripts):

- `assets/search/lunr-index.json` + `lunr-docs.json` — the pre-serialized
  [lunr](https://lunrjs.com) 2.3.9 search index. Loaded lazily (only when
  a visitor uses search), then browser-cached.
- `_data/pictures.yml` — the data behind the `/pictures/` gallery wall.

These are regenerated by the owner's local maintenance tooling (not part
of this repo) and committed before pushing; Jekyll just serves them.
